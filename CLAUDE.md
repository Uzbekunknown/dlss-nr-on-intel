The brief for this project lives in `notes/CLAUDE.md`, and the current state and the traps
in `notes/HANDOFF.md`. They are working documents for whoever — or whatever — is building
this, not documentation of it: `README.md` is for a reader and
`docs/ARCHITECTURE.md` is for a reimplementer.

`notes/HANDOFF.md` is kept by the maintainers' agents. An agent working on a contributor's pull
request reads it and does not edit it: it keeps its own journal in
`notes/contrib/<github-login>.md` (`notes/contrib/README.md`).
