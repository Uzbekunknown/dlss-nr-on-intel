# Contributors' journals

`notes/HANDOFF.md` is the maintainers' working file: read it for the state of the work, the rules
for every change and the traps, but do not edit it. If you, or an agent working for you, keep notes
while you work on a pull request, keep them here, in a file of your own:
`notes/contrib/<your-github-login>.md`, committed with the pull request. When it is merged, the
maintainers carry what matters from it into `notes/HANDOFF.md`.

Newest entry first. An entry says:

- the date, and the branch or pull request;
- what changed, and why;
- how it was checked: the GPU, driver and system, the tests that ran, and the numbers;
- what did not run, or is not proven;
- what you need from the maintainers.

Write it for the next person who reads it: what changed and how it was proven. No personal data,
and nothing about your own machine beyond the GPU, driver and system a result came from.
